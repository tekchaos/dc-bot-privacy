# 🔒 Privacy Policy – DC BOT (BOT ᴷᴹᴬ)

**Last Updated:** 28.08.2026  
**Responsible:** cay.66 (Developer & Owner)

---

## 1. What data does the bot process?

DC BOT by cay.66 processes only Discord-related data required for technical functionality:

- User ID  
- Username / Nickname  
- Server ID  
- Channel ID  
- Roles & Permissions  
- Interaction data (Slash Commands, Buttons, Modals)  
- Message content **only** if the server has enabled the “Message Content Intent”

---

## 2. Why is this data processed?

The bot uses this data to provide the following features:

- Giveaway system (start, end, reroll, winner selection)  
- Logging system (server logs, giveaway logs, role logs)  
- Moderation tools (warnings, mutes, bans)  
- Role automation  
- Event modules  
- Interaction modules

---

## 3. Data storage

- Temporary data is deleted immediately after the action  
- Giveaway logs are stored to ensure transparency  
- Moderation logs may be stored permanently if the server enables it  
- No data is shared with third parties  
- No external services receive user data

---

## 4. Access to data

- Only the developer (cay.66) has access  
- No automated external access  
- No third-party integrations

---

## 5. Data deletion

Users may request deletion of their stored data at any time:

- Via DM to the developer  
- Via a ticket on the server  
- Via the command `/privacy delete`
